# A-Multimodal-Dataset-Integrating-Near-Infrared-Optical-and-Wearable-Sensor-Signals-for-Non-Invasive-
Multimodal, non-invasive diabetes classification dataset: 15,720 rows by 56 columns merging NIR optical (660/940 nm), wearable physiological and demographic features from 5 sources (56% real, 44% synthetic). Stratified 70/15/15 splits, EDA package, data dictionary, and eight ML baselines.
